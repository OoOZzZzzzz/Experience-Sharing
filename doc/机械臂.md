## 🧠 机械臂核心知识速览

<a id="core"></a>

> 这部分是结合公开资料整理的「认知地图」，先建立框架，再动手实践效率最高。

### 1. 自由度（DoF）是什么

<a id="dof"></a>

机械臂的**自由度（Degree of Freedom）**指独立可控的关节数量，每个旋转/移动关节贡献一个自由度。

- **3 自由度**：只能到达三维空间中的某个点，**姿态不可控**（如 SCARA 取放）。
- **4 / 5 自由度**：姿态部分可控，常在低成本玩具臂上出现，**常被商家误标为"六自由度"** ❗。
- **6 自由度**：末端可在空间中**任意定位 + 任意定姿**，是通用工业机械臂的基本配置 ✅。
- **7 自由度**：冗余自由度，多一个轴用于**避障 / 优化姿态**（如 KUKA iiwa、UR 系列）。

### 2. 驱动方式三选一：舵机 / 步进 / 无刷伺服

<a id="drive"></a>

| <span style="white-space:nowrap">驱动方式</span> | <span style="white-space:nowrap">位置控制</span> | <span style="white-space:nowrap">速度控制</span> | <span style="white-space:nowrap">力矩控制</span> | <span style="white-space:nowrap">精度</span> | <span style="white-space:nowrap">成本</span> | <span style="white-space:nowrap">适合场景</span> |
| --- | :-: | :-: | :-: | :-: | :-: | --- |
| <span style="white-space:nowrap">🎛️ **普通舵机**</span> | <span style="white-space:nowrap">✅</span> | <span style="white-space:nowrap">❌ 不连续</span> | <span style="white-space:nowrap">❌</span> | <span style="white-space:nowrap">低</span> | <span style="white-space:nowrap">💰 低</span> | <span style="white-space:nowrap">入门玩具、低成本演示</span> |
| <span style="white-space:nowrap">🪜 **步进电机 + 减速器**</span> | <span style="white-space:nowrap">✅</span> | <span style="white-space:nowrap">✅</span> | <span style="white-space:nowrap">✅（力矩较小，靠减速器增扭）</span> | <span style="white-space:nowrap">中</span> | <span style="white-space:nowrap">💰💰</span> | <span style="white-space:nowrap">自制机械臂主流方案</span> |
| <span style="white-space:nowrap">🧲 **无刷伺服（BLDC + FOC + 编码器）**</span> | <span style="white-space:nowrap">✅</span> | <span style="white-space:nowrap">✅</span> | <span style="white-space:nowrap">✅ 力矩大</span> | <span style="white-space:nowrap">高</span> | <span style="white-space:nowrap">💰💰💰</span> | <span style="white-space:nowrap">协作机械臂、人形机器人</span> |

> 📌 结论：**预算紧张/练手选舵机**，**追求精度与工程价值选步进 + 减速器**，**不差钱/搞研究选无刷伺服**。选型直接决定关节的动态上限、控制带宽与集成难度。 [cite:7ac6cc53-2]

### 3. 减速器三兄弟：行星 / 谐波 / RV

<a id="reducer"></a>

电机转速快、扭矩小，必须通过减速器转换为「低速大扭矩」。机械臂关节里最常见的是三种精密减速器：

| <span style="white-space:nowrap">类型</span> | <span style="white-space:nowrap">特点</span> | <span style="white-space:nowrap">常用位置</span> |
| --- | --- | --- |
| <span style="white-space:nowrap">🪐 **行星减速器**</span> | <span style="white-space:nowrap">结构紧凑、成本友好、通用性强</span> | <span style="white-space:nowrap">自制臂主流（ZERO / 6轴Agent 都在用）</span> |
| <span style="white-space:nowrap">🌊 **谐波减速器**</span> | <span style="white-space:nowrap">小体积内做到高减速比 + 高精度</span> | <span style="white-space:nowrap">协作臂关节（Dummy 机械臂使用）</span> |
| <span style="white-space:nowrap">🏋️ **RV 减速器**</span> | <span style="white-space:nowrap">刚度高、抗冲击、重载</span> | <span style="white-space:nowrap">工业机器人重载关节</span> |

> 💡 简单记忆：**行星 = 性价比通用，谐波 = 紧凑高精度，RV = 重载硬骨头**。 [cite:7ac6cc53-3]

### 4. 零基础学习路线

<a id="learn-path"></a>

**Step 1｜理论基础（1~2 个月）**
- 📖 教材：John Craig《Introduction to Robotics: Mechanics and Control》（机器人学导论），配套斯坦福 Oussama Khatib 教授的公开课视频，B 站/YouTube 均可找到。 [cite:0b4dfc28-1]
- 📺 中文教程：[B 站机械臂运动学教程（林沛群）](https://www.bilibili.com/video/BV1oa4y1v7TY/)——覆盖旋转矩阵 → 变换矩阵 → DH 建模 → 逆解 → 轨迹规划全流程。 [cite:0b4dfc28-2]

**Step 2｜核心概念（对照项目理解）**
- **DH 参数**：连杆长度 $a_i$、连杆扭转 $\alpha_i$、连杆偏移 $d_i$、关节角 $\theta_i$——描述机械臂几何的"标准语言"。 [cite:0b4dfc28-3]
- **正运动学（Forward Kinematics）**：给定关节角 → 求末端位姿。
- **逆运动学（Inverse Kinematics）**：给定末端位姿 → 求关节角（更常用、更难）。
- **轨迹规划 / 雅可比矩阵 / 动力学**：进阶内容。

**Step 3｜动手实践（按项目爬升）**
1. 🍼 舵机玩具臂 → 理解 PWM 控制
2. 🐢 LeRobot 双臂 → 遥操作 + 数据采集 + 模仿学习
3. 🟢 ZERO → 步进 + 减速器 + PID + 运动学仿真
4. 🏆 Dummy → 谐波减速 + FOC + 上位机，全栈通关

> 📌 一句话：**先啃 Craig，再玩 LeRobot，最后挑战 Dummy**。

> 💭 基于 Annin Robot 二次开发的 6 轴联动机械臂。

<img src="image/Picker%20RobotV1.jpg" alt="Picker RobotV1" style="zoom: 20%;" />

**📦 Picker 分为 2 个版本**

- **步进电机版本 V1**、**无刷伺服电机版本 V2**，其中 V2 版本结构适配 V1 的步进电机，且采用光电开关，精度更高，建议同学优先考虑制作 V2 版本。
  - `hardware`：内含两个电路板（光电开关 + 主控 IO 板），需自行生产贴片，绘制软件为立创专业版。
  - `firmware`：机械臂主控驱动程序，使用 Arduino IDE 烧录；夹爪扩展板程序用于控制舵机夹爪。
  - `software`：机械臂上位机软件及源码，软件版本跟随 AR4 版本更新可升级。
  - `Model`：需打印的 3D 打印结构，建议使用**尼龙烧结工艺**制作。
  - `Docs`：DH 参数、Arduino 安装程序、接线图、无刷电机手册、上位机等（V1 内含步进电机手册及上位机），V1/V2 接线原理相同。
  - `Bom`：采购材料清单，其中 J6 齿轮需要二次加工。

## ⚠️ 安全提示

<a id="safety"></a>

> 机械臂一旦上电就是一台"暴力机器"，请务必遵守以下安全守则： [cite:4f97d428-5]

- ✅ 运行前清空机械臂工作空间 **1 米范围**内的贵重 / 易碎物品、线缆等
- ✅ 调试与运行期间，**人员禁止靠近机械臂运动范围**
- ✅ 上电后请勿用手触碰关节、电机、连杆、夹爪或末端工具
- ✅ 运行舵机设置、校准、遥操作、数据采集、回放或评估前，**确保机械臂固定牢靠**
- ✅ 如出现异常运动，**立即断电**
